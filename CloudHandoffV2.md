## 2. Things you must know before touching a group

1. **The game was assembled with `as1 -r4300_mul`** (VR4300 multiply
   errata): 90 game functions contain `mul; nop; mul`. See
   [cloud/work/R4300_MUL.md](cloud/work/R4300_MUL.md). `score.py` does not
   pass the flag yet (a maintainer change, requested). Until it does, score
   with [cloud/work/tools/zbuild.py](cloud/work/tools/zbuild.py):
   ```bash
   python3 cloud/work/tools/zbuild.py cloud/work/ipa-groups/<id> --as1=-r4300_mul
   ```
   It builds like `score.py group` and compares each member with the same
   strict `score.compare`. It also prints each function's emitted size,
   which tells you quickly about inlining or unrolling.
2. **Do not edit** `tools/cloud/score.py`, `CloudHandoff.md` or
   `tests/conveyor/test_cloud_score.py` (maintainers' files), or anything
   already spliced into `src/blob/`.
3. **Other helpers** in `cloud/work/tools/`: `tdis.py NAME` disassembles the
   retail words with `jal` targets named (needs
   `apt-get install binutils-mips-linux-gnu`). `callers.py NAME` lists who
   `jal`s a function. `closure.py [GROUP...]` prints each group's missing
   IPA partners (the closure gaps in section 5; approximate).

## 3. Seed defects that recur (check every new group for them)

- **Undeclared `fabsf`/`sqrtf`.** m2c emits them for `abs.s`/`sqrt.s`.
  Undeclared, cfe compiles an implicit-`int` external call, which adds about
  30 words and an unresolved symbol. Add at the top of `group.c`:
  ```c
  float fabsf(float);
  float sqrtf(float);
  #pragma intrinsic (fabsf)
  #pragma intrinsic (sqrtf)
  ```
- **IPA parameters in register order.** The generator orders `ipa_*`
  parameters by register. The real order comes from the prologue's
  home-slot stores (`sw $t2,4(sp)` means parameter 1, and so on); check it
  against the caller's `jal` setup. `func_800E4300` was the example:
  `(s16 *pos, s16 t2, s16 t5, s16 a1, s16 t0)`.
- **A home-slot store followed by `sll 16`/`sra 16`** means an `s16`
  parameter.
- **Stack locals passed by address** (`&sp60`) must be real arrays or
  structs, not separate scalars.
- **Missing callers or callees (closure gaps).** A member's register choice
  depends on every function it exchanges non-ABI registers with. A group
  that lacks one cannot match however good the C is. Each STATUS lists its
  gap. This is the biggest blocker left.

## 4. Techniques that produced the matches

- **Recognize library code.** The 18 zlib functions matched straight from
  the zlib 1.0.4 source with a few game edits (`IPos` is `ush`, no
  `msg`/`status`/`strategy`, `deflate_slow(s)` has no `flush`). Look for
  other libraries by their constants and tables before decompiling by hand.
- **Inlining control.** `#define local` (so statics become globals that
  `uld` internalizes) keeps IPA without extra inlining. Use `__inline` where
  the target inlined five call sites. Delete dead stubs; they add words.
- **Keep list.** Any function with callers outside the group goes in
  `keep`, or IDO gives it IPA registers it did not have.
- **Hand-writing from the assembly** beat fixing seeds for the path graph
  (`func_800B9B64`): typed structs (`PathGraph` at `D_801407F0`), plain
  loops, parameters in the order found above.
- `#pragma intrinsic (sqrtf)` gives `sqrt.s`. A `(u32)` float conversion
  gives the `cvt.w.s` + FCSR + `0x4F000000` sequence.

## Findings worth reusing

- `as1` merges consecutive `lui at` only when the symbol is *defined* in the
  same unit (not `extern`); this fixed `player_*_set`.
- Launder a pointer through `(u32)` to stop uopt hoisting loads above stores
  (`camera_scene_manager` family).
- `volatile` fields stop CSE where the target does not CSE.
- Named locals become uopt webs and get registers in a different order from
  expression temps; drop or add them to steer allocation.
- `(u32) slot * 0x18` avoids reusing a hoisted `li 24` for `multu`.
- Natural source (typed struct arrays, plain `for`) beats m2c shape; K&R
  callee prototypes remove `lh` narrowing of arguments.
- IPA gives a parameter the first register above the callee's outgoing
  argument count; this blocks `func_8008B640` and `_a`.
