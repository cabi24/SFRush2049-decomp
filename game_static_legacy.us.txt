// Game-side names of renamed static functions (hand-maintained; not generated).
//
// When a static function is renamed in symbol_addrs.us.txt before its game
// callers are, this file keeps the old name at its address for the game link
// only: pipeline.blob_tu.static_symbols() gives the game link these names (they
// win over the static name at the same address); the static ROM link never
// reads it. Remove an entry only after every game caller has been renamed and
// the image re-proven.
//
// Lane w22g used it for its 43 libultra renames (docs/SYMBOL_MISATTRIBUTION.md).
// Lane w23g renamed every game caller (src/blob, the groups' context copies and
// cloud/matches) and re-proved the image, so no entries remain. The runtime
// images resolve against their own frozen asm/us/ovl_*/symbols.json.
//
// Format: symbol_addrs (NAME = 0xADDR; // static name NEW).
