# Executable work-package catalog

Baseline and definitions: [PROJECT_PLAN.md](../../PROJECT_PLAN.md). Audited on 2026-10-03 against master `53d0fba0c5f44e91fe921f722fee7ff63a2dd0fe`.

These 65 primary cards and two concrete child cards are proposed work, not assignments or matching promises. All owners start **unassigned** unless a live claim/PR says otherwise. Priority P0 protects trustworthy progress; P1 unlocks source and execution; P2 develops admitted families; P3 covers later completion. Priority is not a time estimate. Dependencies refer to evidence required for the dependent claim, not a prohibition on useful disjoint preparation.

Every card inherits the following contract: obey owner restrictions; reserve exact native intervals and edited paths; inspect current locks/PRs/archive; work in isolation; use C89/true native ABI where applicable; preserve licenses; record source/recipe/target hashes and commands; distinguish historical inspection from fresh tests; publish no raw ROM/native dumps; independently review before acceptance. Deliver findings in `cloud/work/<packet-id-and-subject>/` or the established packet, tests in the appropriate suite, and a short status with one next action. New matching submissions use the existing dedicated matching routes. This catalog itself changes no code or policy.
