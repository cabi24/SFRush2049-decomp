# Data Model: Corpus Candidates

Deltas against the 001 schema (`tools/conveyor/coordinator/db.py`). All migrations
idempotent (see research D7). Nothing existing is renamed or rewritten.

## New table: `corpus_root`

| Column | Type | Notes |
|---|---|---|
| `origin` | TEXT PRIMARY KEY | short name, e.g. `ultralib`; MUST NOT be `arcade` |
| `path` | TEXT NOT NULL | repo-root-relative clone path, e.g. `reference/repos/ultralib` |
| `repo_url` | TEXT NOT NULL | provenance only, never fetched |
| `commit_sha` | TEXT NOT NULL | recorded at register; re-checked at ingest; `-dirty` suffix iff `--allow-dirty` |
| `include_dirs` | TEXT NOT NULL DEFAULT '[]' | JSON list of root-relative include dirs, e.g. `["include"]` |
| `ingested_at` | TEXT NULL | ISO8601; NULL until first successful ingest |

## Extended table: `arcade_candidate`

New columns (existing rows keep defaults):

| Column | Type | Notes |
|---|---|---|
| `origin` | TEXT NOT NULL DEFAULT 'arcade' | `'arcade'` or a `corpus_root.origin` |
| `provenance` | TEXT NOT NULL DEFAULT '{}' | JSON `{repo_url, rel, commit}`; `{}` for arcade |

### candidate_id grammar

- Arcade (unchanged): `"<rel>:<name>"` — e.g. `game/attract.c:InitAttract`
- Corpus (new): `"<origin>:<rel>:<name>"` — e.g.
  `ultralib:src/os/createmesgqueue.c:osCreateMesgQueue`

Parsing invariants (single source of truth; do not ad-hoc re-parse):

- `name = candidate_id.rpartition(":")[2]` — valid for both forms.
- Source resolution goes through the row's `origin` column: `arcade` → the arcade
  tree constant; otherwise `corpus_root.path` joined with `rel` (which is
  `candidate_id.rpartition(":")[0]` with the leading `"<origin>:"` stripped).
- Uniqueness: PRIMARY KEY on `candidate_id` suffices — corpus ids are prefixed by
  origin, arcade ids never contain a first segment matching a registered origin
  (registration MUST reject an origin name containing `/` or `.c`).

## Extended table: `matrix_entry`

| Column | Type | Notes |
|---|---|---|
| `score_reloc_blind` | INTEGER NULL | NULL for cells scored by pre-002 toolkits; 0 = masked-word identical |

Invariant (FR-007): whenever `score = 0`, `score_reloc_blind` MUST be 0 for cells
produced by 002+ toolkits. Ingest MUST NOT reject old result blobs lacking the field
(writes NULL).

## `function_status.human_flag` — new value

`'reloc_only_diff'` joins `'no_ancestry'` in the existing free-text advisory column.
Semantics: best evidence for this target has `score_reloc_blind == 0 AND score > 0`.

State rules (no new states in the transition engine):

- Set during corpus results ingest only if the target's status is `unmatched` and it
  has no manual override (mirrors the `no_ancestry` rule in `update_rankings`).
- Recomputed from `matrix_entry` on every corpus ingest: the flag clears if fresh
  evidence stops satisfying the condition, and is superseded by the normal
  `candidate_identified` path if true score 0 appears (FR-011).
- Never a promotion input: `verify_promote`, the lock, and `update_rankings`
  promotion logic MUST NOT treat it as matched (SC-007).

## Result cell schema (job payload, node-side)

`compile_score` result cells gain one key:

```json
{
  "candidate_id": "ultralib:src/os/createmesgqueue.c:osCreateMesgQueue",
  "flagset": "-g0 -O1 -mips2 -G 0 -non_shared",
  "target_id": "osCreateMesgQueue",
  "score": 20,
  "score_reloc_blind": 0,
  "compile": "ok"
}
```

`score_reloc_blind` is present iff `compile == "ok"` (same rule as `score`).
Manifest schema is unchanged — corpus jobs are ordinary `compile_score` manifests,
so dedupe (manifest_sha incl. `input_shas`) applies untouched.

## Match artifact: `work/<...>/<target_id>/corpus_match.c`

Written for `reloc_only_diff` targets only. Location: the target's existing work
directory found by the `verify_promote` rglob rule; fallback
`work/corpus/<target_id>/`. Overwritten on re-ingest (artifact is derived state,
never hand-edited; header says so). Format:

```c
/*
 * CORPUS MATCH (reloc_only_diff) — NOT byte-verified; do not commit as matched.
 * Generated by pipeline.corpus; regenerated on every ingest — do not hand-edit.
 * Origin:      ultralib (https://github.com/decompals/ultralib)
 * Source:      src/os/createmesgqueue.c @ e24c8367
 * Flags:       -g0 -O1 -mips2 -G 0 -non_shared
 * Scores:      true=20  reloc_blind=0
 * Upgrade:     re-scores automatically when relocation-aware targets land
 */
<candidate source body>
```

## Entity relationships

```text
corpus_root 1 ── * arcade_candidate(origin)      [origin FK by convention]
arcade_candidate 1 ── * matrix_entry(candidate_id)
n64_target 1 ── * matrix_entry(target_id)
n64_target 1 ── 0..1 match artifact              [derived from matrix_entry]
```
