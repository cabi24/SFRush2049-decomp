// splat relocation naming overrides (rom:<ROM offset> reloc:<type> symbol:<base> addend:<offset>).
//
// splat names every address a %hi/%lo pair reaches as its own D_ symbol. Where the
// original code reached that address as base+offset (array element, field, end
// pointer), the listed instruction is named base+addend instead, matching the
// relocation IDO emits for the byte-identical C. Only these instructions change;
// the split symbols remain, as do their other references. Linked bytes are identical.
//
// Each entry is proposed by `python3 -m tools.conveyor.pipeline.reloc_split derive
// <fn> --candidate <IDO .o>`, which refuses a wrong global or a wrong addend.
// `reloc_split check` verifies every entry against the ROM word it names.
// Regenerate: make extract (GLOBAL_ASM slots). Promoted slots keep their asm.
// See cloud/work/boot_tail_promotion/WAVE4.md.
