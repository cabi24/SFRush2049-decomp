# A86/A87 native jump-table window placement

Complete genuine native sources reproduce menu_option_toggle (79 words) and menu_text_input (87 words), each with real accepted format_string_parse context (45 words). Their native group objects pack two adjacent tables into one .rodata section; the original ROM places those tables at separate image addresses. The former one-base section placement therefore refused these otherwise exact sources. Frozen lead source hashes and empty claims are unchanged.

The implementation in tools/conveyor/pipeline/blob_group.py first runs the unchanged contiguous section proof. A successful single-base placement immediately returns without examining context-only relocations, including pairs cut by a context extent. Only an existing refusal can select the new .rodata fallback. It derives separate windows from actual native HI16/LO16 table-start references in genuine covered member/context text, and verifies every pair agrees on the window's original address.

The fallback requires every used section word to be a unique aligned R_MIPS_32 entry targeting aligned genuine covered text. It requires a complete contiguous partition from section offset zero, checks every original relocated table byte independently, and refuses overlapping image windows. Trailing zero alignment bytes retain their existing treatment. Unknown or unsupported entry kinds, incomplete/duplicate/unaligned sites, uncovered text targets/references, addends outside verified windows, conflicting references, missing entries, mixed non-table words and nonzero unmapped data refuse. No source padding, scorer masks, reduced word checks or unknown-reference allowances were introduced.

The new test file tests assembled two-table objects through the actual relocation API, with distinct original placements, member-only reconstruction and context table validation; it also tests exact-byte corruption, overlapping images, unknown/out-of-range/unaligned entry targets, incomplete partitions, malformed relocation metadata, conflicting/incomplete references, and the two requested legacy context-compatibility cases. All47 focused tests (21 existing plus26 new) pass with captured pytest exit0. Independent root fresh D A86/A87 objects also reproduce both full caller/helper bodies and normal member-only reconstruction exactly. Root owns real-table corruption drills, full tests, strict score, ROM/image/lock gates and publication. Only blob_group.py and the new targeted test file were edited in shared tooling.
