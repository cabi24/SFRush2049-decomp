## What was learned

The baseline's hand-expanded vector checks lacked a consumed squared-distance
local. Adding it recovers the native f0 result instead of a temporary FP lane.
Explicit do/while(0) edge statement regions recover the native saved-register
choices; original source or macro spelling remains unknown. Existing arrays
remain hit[3], normal[3][3], corners[4][3] and delta[3]. Existing local order
exposes the native vector and index homes.

The draft contains thirteen plainly named UNUSED s32 declarations, solely a
**diagnostic exact-frame allowance**, following the documented Wave 12/16
policy. Removing them from this same source gives 192 bytes. Their 52 named
bytes plus four bytes of frame alignment close the exact 56-byte gap to 248.
They establish neither original variables nor capacities. They are not
semantic reconstruction evidence, and the result is still NONMATCH.
The no-allowance source remains reproducible: 154/305 and 1,208 emitted bytes.

Stock UGEN diagnostics and a pre-existing, unforced W5D/colour tracer each
produce an entire object byte-identical to ordinary stock IDO. The final
source has M196/T28/P8. High-debug W5D level 3 crashes before producing useful
output; level 0 instrumentation is stock-identical. No conclusion is based on
the failed diagnostic run.

The dominant remaining cause is the consumed ring index's allocator web 158:
net saving 5 versus spill cost 2 selects t0. A **diagnostic-only forced split**
of that one web reproduces the native 1,220-byte extent and leaves exactly
seven word differences:

- Four words at +0x310/+0x318/+0x31c/+0x324: the same three final vector
  stores and global-address completion are scheduled in a different order
- Three words at +0x3a0/+0x3e4/+0x480: the computed selected-object cursor is
  stored/reloaded at sp+60 rather than native sp+56

This force is neither source nor stock output. It is never accepted, installed
or used for matching credit. Independent full GNU linking reproduces all seven
sites. The forcing hook reports a second split of the same web after splitting;
this is not claimed to be an exact recovered compiler decision history.

Separate consumed cursor/index forms, explicit induction, index signedness,
no-code index reads and nearby statement-region variations did not recover the
native memory-only index choice. No such ineffective form is retained. A
possible adjacent deleted-helper theory was tested but did not explain native
geometry; no fictitious helper is retained. Stop broad source guessing here.
The useful next step is an original local-lifetime or inline-region witness
that explains the index split and cursor spill order.

## Native contract and verification

The full authenticated native caller census contains only
`entity_physics_update+0x258`. Its call derives a0 from the player-position row
and retains that same player index in a1. Thus the two-input reconstruction is
supported even though older game-side source prototypes show one argument.
This packet does not edit those prototypes or claim the larger caller matches.
The four external helper bodies and every referenced binding are input-bound.

The verifier independently GNU-links the original object and original REL
records for baseline, draft and no-frame-allowance control. It checks every
complete STT_FUNC extent, native next boundary, each word including absent
native tail words, allocated-section set, exact symbol bindings, zero suffix
and absence of remaining relocations. Baseline has 19 text relocations; both
shaped forms have 25. There are no owned data sections or waived relocations.
Only the intrinsic fabsf may remain unreferenced in the input symbol table.

Protocol-v2 receipt binds all executable packet files, test, current baseline,
selected complete native rows, symbols, genuine caller, external helper bodies
and all eight stock IDO pass executables. It does not pin whole shared tools,
locks, Makefiles or generated assembly text. No static ROM TU is rebuilt.

Actual candidate C and current-tree baseline agree across **345,600 finite
logical-host cases**: four players, compression below/equal/above the limit in
each wheel, all 16 terrain-hit masks, nine height/distance geometries, every
ring index, wrapped/unwrapped rings and two nullable-handle patterns. Complete
helper event sequences, final ring state and input position verify. The same
matrix passes ASan/UBSan (only LeakSanitizer disabled). These are deterministic
helper doubles and baseline-equivalence checks, not execution of retail helpers
or native gameplay. The diagnostic unused locals contribute no behavior.

Normal and optimized-Python replay, canonical expected-NONMATCH score, stock

exceptional FP state, asynchronous helper behavior, image composition and
