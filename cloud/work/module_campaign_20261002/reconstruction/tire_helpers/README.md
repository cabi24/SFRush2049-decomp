# Bounded dotireforce donor controls

These four research sources remain unmatched and claim no coverage. The actual
native target is `camera_follow_target` at 800BCBB8, 203 instructions / 812 bytes.
Its direct arcade ancestor is `tires.c:dotireforce`; the N64 port retains the
genuine unused final `airfact` formal while dropping the opposite tire-velocity
argument, for fourteen ordinary parameters.

The fresh controls use real Model2056 and Tire92 fields, consumed donor local
values, the native force-vector comparison, and source constant spellings.
Ordinary O2 results were 179/203 differing words for donor local order,
182/203 for the force-vector comparison, 182/203 plus ten unverified pool
references for native constants, and 179/203 plus ten unverified pool references
for the original donor constant types. None exceeded the independent compiler
lane's typed baseline. The compiler lane owns subsequent helper-context work.

Numeric receipts are retained under `receipts`; objects and disassembly stay in
ignored build storage. These controls are frozen; they do not change accepted
helpers or supply source padding to force the native 96-byte frame.
